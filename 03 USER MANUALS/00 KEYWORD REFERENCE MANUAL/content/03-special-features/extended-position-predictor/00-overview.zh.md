# 扩展位置预测器（EPP）

EPP 是一种用于重复运行运动的重复控制（迭代学习）前馈功能。它不对位置反馈进行滤波，而是从一次运行中学习修正量并在下一次运行中应用，使重复轨迹每次执行时的跟踪精度不断提升。

每次运行期间，在运动激活时，EPP 执行以下操作：

1. 获取位置误差 [PosErr]，并通过一个超前/滞后（LL）IIR 滤波器处理，该滤波器的抽头由 [EPPNumInteg]/[EPPNumFract]（分子）、[EPPDenInteg]/[EPPDenFract]（分母）、[EPPFiltLength]（有效抽头数）和 [EPPNumFactor]（分子总增益）设定；
2. 加上上一次运行中存储的前馈修正向量（第一次运行时该存储向量为零，因此第一次运行不贡献任何已学习的修正量）；
3. 将结果通过一个二阶低通滤波器，其截止频率和阻尼由 [EPPModelRange] 设定；
4. 将结果作为下一次运行的修正向量存储回去；并
5. 将修正量叠加至电流参考 [CurrRef]。

EPP 仅在位置控制模式下运行，不用于步进电机。[EPPRequest] 选择某次运行是启动学习（第一次运行）还是继续学习（重复运行），[EPPState] 报告该功能当前的工作状态。
