# AOutShifts

*旧版关键字*

**定义：**

AOutShifts 定义模拟量输出的左移或右移位数，以改善动态范围。数组索引对应模拟量输出的编号（即：AOutShifts\[2\] 对应模拟量输出 2）。

对于 AOutShifts，负值表示右移/除法，正值表示左移/乘法，零值表示不进行移位。

AOutShifts 为负值时，操作为右移位，仅对非负源值等效于截断除法；对于负源值，将向负无穷方向取整。例如，若初始值为 -9423 且 AOutShifts=-5，则结果值为 -295。

**注意：**

AOutShifts 仅在监控模式下有效（AOutMode != 0）。
