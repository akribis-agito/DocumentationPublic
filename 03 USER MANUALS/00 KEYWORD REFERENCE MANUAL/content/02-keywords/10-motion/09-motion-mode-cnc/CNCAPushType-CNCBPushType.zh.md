# CNCAPushType/CNCBPushType

将新运动段推入 CNC FIFO 队列 A（或 B）的指令。

## 概述

`CNCAPushType`（及其在第二 CNC 引擎上的对应项 `CNCBPushType`）在队列 A（或 B）的 CNC 段队列（FIFO）中打开一个新段。该单一指令值同时包含**段类型**（直线、圆弧、螺旋、延时等）和**涉及轴**列表。类型推送后，段的参数通过 [CNCAPushParam/CNCBPushParam](CNCAPushParam-CNCBPushParam.md) 逐个提供；仅当最后一个所需参数被推送后，该段才成为完整的队列条目。通过以太网时，[CNCAPushSeg/CNCBPushSeg](CNCAPushSeg-CNCBPushSeg.md) 可在单条消息中推送类型和所有参数。

这是一个非轴指令功能，可在任何时刻（包括运动中）发出，因此上位机可在控制器回放队列中已有段的同时持续向队列填充内容。

## 工作原理

### 推送 → 队列 → 回放 → 耗尽流水线

CNC 流水线是一个生产者/消费者队列：

1. 上位机**推送**段：一次 `CNCAPushType`（预留段并记录所需参数数量），随后恰好进行该数量的 `CNCAPushParam` 写操作（或通过以太网进行单次 `CNCAPushSeg`）。
2. 每个完整推送的段按推送顺序**排入**段 FIFO（[CNCAFIFO/CNCBFIFO](CNCAFIFO-CNCBFIFO.md)）。
3. 运动引擎**回放**最旧的队列段，每个控制采样推进路径一步。当一个段结束时，引擎取下一个段。配置和副作用段（如 I/O 写、数组写或矢量/转角参数更改）立即应用，引擎随即继续执行下一段；延时段也是非运动段，但它会在请求的时间内主动保持路径；等待类型段则保持路径直到其条件满足。
4. 每个段被消耗后从队列中**耗尽**，释放其空间供新的推送使用。

若引擎到达需要新段的时刻，但队列中没有完整的运动段——无论是因为队列为空，还是因为上位机仍在推送最后一个段的参数中途——运动将结束（**欠运行**）。为避免欠运行，请持续推送，使至少一个完整段始终在当前回放段之前排队等待。通过 [CNCAStatus/CNCBStatus](CNCAStatus-CNCBStatus.md) 监控空闲空间。

### 指令值编码

指令值是一个 32 位字段。高字节选择段类型；低 24 位以每 4 位为单位按顺序选择最多六个涉及轴：

| 位 | 字段 | 含义 |
|----|----|----|
| 31–24 | 段类型 | 下表中的值之一。 |
| 23–20 | 涉及轴 1 | 轴索引：`0` = A，`1` = B，`2` = C，……`14` = 第 15 轴。`15` = 该槽无轴。 |
| 19–16 | 涉及轴 2 | 同上。 |
| 15–12 | 涉及轴 3 | 同上。 |
| 11–8 | 涉及轴 4 | 同上。 |
| 7–4 | 涉及轴 5 | 同上。 |
| 3–0 | 涉及轴 6 | 同上。 |

槽值为 `15` 表示"此处无轴"，因此涉及轴的数量为持有小于 15 的值的槽的数量。

### 段类型

[CNCAPushParam/CNCBPushParam](CNCAPushParam-CNCBPushParam.md) 值的所需数量取决于其类型，对于可变类型，还取决于涉及的轴数。

| 类型 | 段 | 涉及轴 | 所需参数 |
|----|----|----|----|
| 1 | 直线运动 | 1–6 | `2 + （涉及轴数）`：每轴一个目标位置，然后是路径速度和终止速度。 |
| 2 | 圆弧 | 恰好 2 | 10：目标 1、目标 2、圆心 1、圆心 2、方向、速度、终止速度、额外整圈数，加上 2 个内部值（推送 0）。 |
| 3 | 螺旋线 | 3–6 | `6 + （涉及轴数）`：每轴目标位置、圆心 1、圆心 2、方向、螺距、速度、终止速度。 |
| 4 | 延时 | 0 | 1：延时时间，单位毫秒。 |
| 5 | 设置矢量动力学 | 0 | 4：速度百分比、加速度、减速度、加加速度。 |
| 6 | 设置转角参数 | 0 | 6：转角类型、转角半径方法、半径/误差、轴加速度、最小转角角度、轴加速度限制类型。 |
| 7 | 设置初始位置 | 1–6 | 每个涉及轴一个起始位置。**仅**允许作为空队列的第一个段。 |
| 8 | 写数字量输出端口 | 0 | 2：轴选择、写入值。 |
| 9 | 写数组 | 0 | 4：数组选择、轴选择、索引、值。 |
| 10 | 相对/绝对目标 | 0 | 1：`0` = 相对，`1` = 绝对。 |
| 11 | 坐标偏置 | 1–6 | 每个涉及轴一个偏置。 |
| 12 | 等待数组值 | 0 | 5：数组选择、轴选择、索引、触发类型、触发值。 |
| 13 | 分配位置 | 1–6 | 每个涉及轴一个位置。 |
| 14 | 自动转角 | 恰好 2 | 10 个内部值（推送 0）；控制器填入计算出的转角。 |
| 15 | 设置每轴最大速度跳变 | 1–6 | `1 + （涉及轴数）`：每轴一个最大速度跳变，然后是速度跳变模式。 |
| 16 | 设置每轴最大加速度 | 1–6 | 每个涉及轴一个最大加速度。 |
| 17 | 写多个数组值 | 0 | 7：数组选择、轴选择、索引，然后是四个值。 |
| 18 | 写多个数组值后等待 | 0 | 10：与类型 17 相同，加上触发索引、触发类型、触发值。 |
| 19 | 修改 CNC 位置滤波器 | 0 | 6：滤波器启用、滤波器类型，然后是四个滤波器参数。 |
| 20 | 3D 圆弧 | 恰好 3 | 20：三个目标、三个圆心坐标、三个附加值、方向、速度、终止速度、额外整圈数，加上内部值（推送 0）。不适用于独立驱动器。 |
| 21 | 等待输入 | 0 | 6：输入选择、轴选择、模拟量输入索引、数字量输入掩码、触发类型、触发值。 |
| 22–25 | 空间事件设置/表/固定间隔 | 0 | 类型相关；配置沿路径的位置触发输出事件。 |

段类型 1–21 在所有固件上均受支持。空间事件类型 22–25 仅在较新固件（develop）上受支持；在 LTS v3.X.X 上，最高有效类型为 21，推送更高类型将被拒绝。3D 圆弧类型（20）也不适用于独立驱动器。

段类型排序规则："设置初始位置"段（类型 7）仅在推入空队列时的第一个推送中被接受；若省略，则第一个**运动**段必须是直线运动（类型 1），且自动转角（类型 14）不能作为第一个或第二个运动段。

连续性规则：运动必须在段间连接处保持连续。若前一段的终止速度不为零，且满足以下任一条件，则推送将因运动不连续而被拒绝：（a）新段为运动阻塞类型（延时、设置位置、相对/绝对、坐标偏置、等待数组、分配位置、写后等待、修改位置滤波器或等待输入），或（b）新段是涉及轴字与前一运动段不同的运动段。[CNCAEndSegMod/CNCBEndSegMod](CNCAEndSegMod-CNCBEndSegMod.md) 选择在此类不连续情况下的处理方式：默认情况下拒绝推送，而值为 1 时则强制将前一段的终止速度设为零并接受推送。

## 示例

```text
ACNCAPushType=value  ; 在 FIFO A 中打开一个编码类型/轴的新段
```

对于在 A 轴和 B 轴上的直线运动（类型 1，轴 1 = 0，轴 2 = 1，其余槽 = 15），该值为 `0x0101FFFF`，随后进行四次 `CNCAPushParam` 写操作（目标 A、目标 B、速度、终止速度）。

### 演练：在队列 A 上排队并运行两段直线运动

在 A 轴和 B 轴上推送两个连续直线段，然后启动运动。第二段的 `EndSpeed = 0`，因此路径在最后一段停止而不会发生欠运行。运动使用 A-B 直线运动（类型 1，两个涉及轴），因此每次 `PushType` 后恰好跟随 `2 + 2 = 4` 次 `PushParam` 写操作：目标 A、目标 B、路径速度、终止速度。

```text
; --- 1) 确保在暂存新路径之前队列为空 ---
ACNCAClear                    ; 清除上次运行的任何残留

; --- 2) 推送段 1：A -> 10000，B -> 5000，路径速度 4000，终止速度 4000 ---
ACNCAPushType=0x0101FFFF      ; 类型 1 = 直线，轴 A (0) 和 B (1)
ACNCAPushParam=10000          ; 目标 A
ACNCAPushParam=5000           ; 目标 B
ACNCAPushParam=4000           ; 路径速度
ACNCAPushParam=4000           ; 终止速度（继续进入段 2）

; --- 3) 推送段 2：A -> 20000，B -> 5000，路径速度 4000，终止速度 0（停止）---
ACNCAPushType=0x0101FFFF
ACNCAPushParam=20000
ACNCAPushParam=5000
ACNCAPushParam=4000
ACNCAPushParam=0              ; 终止速度 0 -> 路径在此段停止

; --- 4) 在 Begin 之前确认两段均已完整构建 ---
ACNCAStatus[5]                ; 0 = 最后推送的段已关闭（就绪）

; --- 5) 使能 CNC 引擎并监视队列耗尽 ---
AMotionMode=11                ; CNCA 运动（CNCB = 17）
ABegin                        ; 引擎开始回放最旧的队列段
ACNCAStatus[10]               ; CNC 运动位域（运动中时第 0 位置位）
ACNCAStatus[7]                ; 空闲字数——随每个段耗尽而增加
ACNCAStatus[6]                ; 当前正在回放的段的队列位置
```

在 `Begin` 运行时持续推送以链接更长的路径——若引擎需要新段但队列中没有已关闭的段，则会发生欠运行。在队列耗尽之前使用 [StopCNCA](StopCNCA.md) 平滑减速路径；使用 [CNCAClear](CNCAClear-CNCBClear.md) 在停止后刷新待处理段。
