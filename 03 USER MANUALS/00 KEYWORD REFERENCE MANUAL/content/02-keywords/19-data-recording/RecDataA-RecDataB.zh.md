# RecDataA/RecDataB

按示波器区分的数组，保存记录元数据和原始（未转换）采集数据。

## 概述

`RecDataA` 和 `RecDataB` 分别存储第一个和第二个示波器的记录元数据及原始采集数据。与 [RecUpload](RecUpload.md) 不同，后者会进行单位转换，而这些数组直接暴露未转换的原始缓冲区内容，适用于自定义分析软件。

> **注意：** 对于仅有单个示波器的产品，查询 `RecDataB` 等同于查询 `RecDataA`。

## 工作原理

每个示波器的元数据存储在数组的前 80 个条目中。原始采集数据（不进行任何单位转换）存储在后续数组条目中，按 [RecParamA/RecParamB](RecParamA-RecParamB.md) 的顺序以通道交错方式排列（每个采样时刻每个通道一个采样）。每个存储值占用一个缓冲区槽，槽的宽度取决于固件：传统固件将每个值存储为 32 位，而较新的固件无论源类型如何均将每个值存储为 64 位——32 位整数被扩展为 64 位，浮点值以其 64 位位模式存储，因此原始浮点数读取时呈现为整数位模式，需重新解释后才能还原为数值。用户可读取元数据和原始采集数据，但总索引上限为 32079；索引大于上限的原始采集数据（即第 32000 条及以后的采集数据）无法通过 `RecDataA`/`RecDataB` 读取。如需流式传输全部采集数据，请参阅 [RecUpload](RecUpload.md)。

`RecDataA`/`RecDataB` 前 80 个索引的说明如下。

| 索引 | 说明 |
|---|---|
| 1 | （若记录在未执行 RecStop 的情况下完成）预期记录的数据点总数；（若记录被 RecStop 中断）中断前最后一个已记录元素的索引 |
| 2 | 每个参数请求的数据点数（RecLength） |
| 3 | 已记录的数据点总数 |
| 4 | 触发位置（RecTrigPos） |
| 5 - 7 | 最大触发值（RecTrigValMax） |
| 8 | 所有用户单位的缩放比例 |
| 9 | 降采样因子（RecGap） |
| 10 - 12 | 触发源（RecTrigSrc） |
| 13 - 15 | 触发位掩码（RecTrigMask） |
| 16 – 18 | 触发类型（RecTrigTyp） |
| 19 - 21 | 触发值（RecTrigVal） |
| 22 | 电流环周期频率 |
| 23 | 第一个已记录元素的索引 |
| 24 | 所有触发条件满足时第一个已记录元素的索引 |
| 25 | 预期最后一个已记录元素的索引 |
| 26 - 45 | 已记录参数的复合 CAN 代码 |
| 46 | 触发模式（RecTrigsMode） |
| 47 – 48 | 触发逻辑（RecTrigsLogic） |
| 49 - 55 | 保留 |
| 56 - 75 | 已记录参数的用户单位 |
| 76 – 80 | 保留 |
