# AdVBusEn

使能直流母线前馈，在母线电压跌落时维持实际输出电压。默认启用。

## 概述

驱动器使用**固定的标称**母线电压将电压指令换算为 PWM 占空比。当实际母线电压跌落时——在剧烈加速、共用电源或较长直流走线的情况下——实际输出电压随之下降，而指令值不变。电机于是悄然得到少于电流环所要求的电压。

当 `AdVBusEn=1` 时，驱动器测量母线电压并按 `标称值 / 实测值` 缩放其电压输出，使实际输出电压与指令值相符。

> **重要：** 与大多数补偿功能不同，本功能**默认启用**。在既有设备上，它会在固件更新后开始生效。

## 工作原理

每个控制周期，实测 [VBus](VBus.md) 经 16 阶滑动平均滤波，电流环电压输出在驱动器施加电压限值之前乘以 `标称值 / 滤波值`。所施加的比值可通过 [VBusRatio](VBusRatio.md) 读取。

标称值与整个滤波窗口在电机使能时从 `VBus` 锁存，并以母线电压不低于 [MinVBus](../../06-protections/02-current-and-voltage/MinVBus.md) 为条件，以防尚未充电完成的母线设定错误的标称值。因此比值从恰好 1.0 开始，启动时不会出现跳变。

> **注意：** 比值被钳位在 **[0.8, 1.2]**。本功能可补偿母线变动最多 20%，超出则不再补偿。该限制是有意设置的——它同时确保完全塌陷的母线不会产生无界的电压指令。

> **示例演算：** 若电机使能时锁存的标称值为 48.0 V，当滤波后的母线为 44.0 V 时，`比值 = 48.0 / 44.0 = 1.091`，驱动器将其电压输出放大 9.1%——正好补回跌落本应造成的损失。当滤波值为 40.0 V 时，计算结果为 1.200，恰好等于钳位值：跌落为 16.7%，补偿仍然精确。而当滤波值为 30.0 V 时，计算结果为 1.600，但比值被**钳位在 1.200**，因此只有前 20% 被补回，其余部分不再补偿。
>
> 读取 [VBusRatio](VBusRatio.md) 即可判断某个轴当前处于上述三种情况中的哪一种。

> **注意：** 实际运动能获得多少改善取决于您的电源以及运动的峰值功率需求，而不取决于本关键字。实测数值请参见《电流环补偿》应用笔记。

### 何时有效，何时无效

| 电源 | 效果 |
|---|---|
| 刚硬、容量充足 | 可忽略——无需补偿 |
| 中等偏弱或共用 | 最为有效；母线变动落在补偿器权限范围内 |
| 容量严重不足 | 帮助有限——跌落超出 ±20% 钳位 |

> **重要：** 本功能换取的是对弱电源或共用电源的**容忍度**，不能替代按运动需求正确选型电源。

### 边界情况

- **标称值是快照而非配置项：** 它是电机使能时的母线电压，即空载工作点。每次电机断使能再使能都会锁存新的标称值。
- **母线塌陷：** 由于除数是锁存的标称值而非实时读数，母线降至零时产生的比值会被钳位，而不会出现除零。
- **滤波滞后：** 16 阶平均相对母线存在滞后，因此非常快速而深的跌落可能被瞬时欠补偿或过补偿。
- **按轴作用范围：** 在 Central-i 主站上每个远程放大器有各自的母线，因此本关键字按轴生效；在独立控制器上母线为整板共用。

## 示例

```text
AAdVBusEn=1           ; 启用（默认）
AAdVBusEn=0           ; 禁用，例如用于对比开启与关闭时的性能
```
