# SinCosSetup/AuxSinCosSet

配置 SIN/COS 编码器接口的参数数组。

## 概述

`SinCosSetup` 是定义 SIN/COS 编码器配置的参数数组。仅当编码器类型（[EncType](EncType-AuxEncType.md)）为 4（SIN/COS 编码器）时使用。数组元素设置信号调理（增益、正弦/余弦偏置、幅值比、相位）、插值、索引（Z）行为、误差检查、方向以及用于校准的测试模式。`AuxSinCosSet` 是辅助编码器的对应项。

> [!warning]
> 请勿将任何单个 `SinCosSetup` 值设置为下表所列以外的值。不当的值可能导致意外的反馈行为，并可能损坏系统。

> **Note:** 可通过 `SinCosSetup[20]` 启用模拟测试模式（TMA）以检查 SIN/COS 信号。时域视图和 X/Y（Lissajous）视图均适用于信号偏置和相位校准。

## 工作原理

下面描述各数组索引。

### [1] 信号增益（默认 2）

设置输入差分 SIN/COS 信号的增益。为充分利用 ADC，请将增益设置为使输入信号达到总共 4 V 峰峰值。

| 值 | 增益 | 值 | 增益 |
|---|---|---|---|
| 0 | 2.667 | 8 | 20.000 |
| 1 | 3.333 | 9 | 26.667 |
| 2 | 4.000 | 10 | 28.571 |
| 3 | 5.333 | 11 | 33.333 |
| 4 | 6.667 | 12 | 40.000 |
| 5 | 8.000 | 13 | 53.333 |
| 6 | 10.000 | 14 | 66.667 |
| 7 | 14.287 | 15 | 80.000 |

### [2] 正弦偏置（默认 0）

校准差分正弦输入的直流偏置。

| 值 | 偏置 [mV] |
|---|---|
| 0 – 127 | -7.8125 * Value |
| 128 – 255 | 7.8125 * (Value - 128) |

例如，`SinCosSetup[2]=33` 给出的正弦偏置为 -7.8125 * 33 = -257.8125 mV。

> [!warning]
> 过高的中心电压可能导致正弦信号的幅值钳位。

### [3] 余弦偏置（默认 0）

校准差分余弦输入的直流偏置。

| 值 | 偏置 [mV] |
|---|---|
| 0 – 127 | -7.8125 * Value |
| 128 – 255 | 7.8125 * (Value - 128) |

例如，`SinCosSetup[3]=203` 给出的余弦偏置为 -7.8125 * (203 - 128) = 585.9375 mV。

> [!warning]
> 过高的中心电压可能导致正弦信号的幅值钳位。

### [4] 幅值比（默认 0）

校准正弦与余弦信号之间的幅值比。

| 值 | 幅值比 |
|---|---|
| 0 – 15 | 1 + (0.1/15) * Value |
| 16 – 31 | 1 - (0.1/15) * (Value - 16) |

例如，`SinCosSetup[4]=19` 给出的幅值比为 1 - (0.1/15) * (19 - 16) = 0.98。

### [5] 相位校准（默认 0）

校准正弦与余弦信号之间的相位差。

| 值 | 相位差 [degrees] |
|---|---|
| 0 – 18 | 90 + (22.5/32) * Value |
| 32 – 50 | 90 - (22.5/32) * (Value - 32) |

例如，`SinCosSetup[5]=12` 给出的相位差为 90 + (22.5/32) * 12 = 98.4375 度。

### [6] 插值因子（默认 0）

定义 SIN/COS 编码器插值因子。

| 值 | 插值因子 |
|---|---|
| 3 – 13 | $2^{\,16 - \text{Value}}$ |

例如，`SinCosSetup[6]=7` 将每个 SIN 或 COS 周期插值为 $2^{\,16-7} = 512$ 每周期计数。

### [7] 迟滞阈值（默认 0）

定义 SIN/COS 信号的数字角度迟滞阈值。它分隔转换器在 CW 与 CCW 运行之间的切换点，若相对于输入噪声设置得足够高，可消除静止时杂散的 A/B 输出切换。

| 值 | 迟滞阈值 [deg] |
|---|---|
| 0 | 0 |
| 1 | 0.087890625 |
| 2 | 0.17578125 |
| 3 | 0.3515625 |
| 4 | 0.703125 |
| 5 | 1.40625 |
| 6 | 5.625 |
| 7 | 45 |

> [!warning]
> 仅建议在校准期间将迟滞阈值设置为 45 度。

### [8] 最大输入频率（默认 16642）

定义 SIN/COS 信号的最大输入频率。在下面的公式中，设 P 为频率因子，Q 为插值因子。

| 值 | 十六进制值 | 频率因子 P | 最大输入频率 [kHz] |
|---|---|---|---|
| 4 | 0x0004 | - | 1200 / Q |
| 16642 | 0x4102 | 0 | $\frac{2000 \cdot 2^{P}}{Q}$ |
| 16898 | 0x4202 | 1 | |
| 17154 | 0x4302 | 2 | |
| 18178 | 0x4702 | 3 | |
| 19202 | 0x4B02 | 4 | |
| 20226 | 0x4F02 | 5 | |
| 21250 | 0x5302 | 6 | |
| 22274 | 0x5702 | 7 | |
| 23298 | 0x5B02 | 8 | |
| 24322 | 0x5F02 | 9 | |
| 25346 | 0x6302 | 10 | |

由于输入频率不能高于 250 kHz，根据插值因子，某些输入频率无法选择：

| SinCosSetup[6] | 插值因子 | SinCosSetup[8] 的最大可能值 | 对应的最大输入频率 [kHz] |
|---|---|---|---|
| 3 | 8192 | 25346 | 250 |
| 4 | 4096 | 24322 | |
| 5 | 2048 | 23298 | |
| 6 | 1024 | 22274 | |
| 7 | 512 | 21250 | |
| 8 | 256 | 20226 | |
| 9 | 128 | 19202 | |
| 10 | 64 | 18178 | |
| 11 | 32 | 17154 | |
| 12 | 16 | 16898 | |
| 13 | 8 | 16642 | |

例如，若 `SinCosSetup[6]=4`（插值因子 4096），则 `SinCosSetup[8]` 的最大值和最小值分别为 24322 和 4，对应的最大输入频率为 250 kHz 和 0.293 kHz。

> **Note:** 建议将 `SinCosSetup[8]` 设置为其最大可能值，以支持尽可能高的编码器速度。

### [9] 输出 A、B、Z 配置（默认 0）

配置增量式 A/B/Z 信号线上出现的信号。通常用于通过数字信号作为 PWM 占空比函数进行校准，而非模拟测试模式（TMA）。

| 值 | 模式 | 所需附加设置 |
|---|---|---|
| 0 | 正常 | 无 |
| 1 | 外部周期计数器的控制信号 | |
| 2 | 校准模式（偏置 SIN / 偏置 COS / 相位） | SELRES = 0x0D, ZPOS = 0x00, HYS = 0x07, ROT = 0x00, CFGAB = 0x00, AERR = 0x00 |
| 3 | 校准模式（偏置 SIN / 偏置 COS / 幅值） | |

### [10] 反转方向（默认 0）

定义 SIN/COS 编码器信号的方向。此设置影响位置读取的方向。

| 值 | 模式 |
|---|---|
| 0 | 递增（B 超前 A）（COS 超前 SIN） |
| 1 | 递减（A 超前 B）（SIN 超前 COS） |

### [11] 周期计数器复位使能（默认 0）

激活后，周期计数器在穿越索引（Z）时复位。

| 值 | 模式 |
|---|---|
| 0 | 停用 |
| 1 | 激活 |

### [12] 零信号位置（默认 0）

配置在何角度断言索引。

| 值 | 角度 [degrees] |
|---|---|
| 0 – 31 | Value * 11.25 |

### [13] 零信号长度（默认 0）

配置索引相对于 SIN/COS 信号断言的持续时间。

| 值 | 长度 |
|---|---|
| 0 | 相对于插值后的 A/B 信号为 90° |
| 1 | 相对于插值后的 A/B 信号为 180° |
| 2 – 3 | 同步；相对于原始 SIN/COS 信号为 180° |

### [14] 零信号逻辑（默认 0）

配置索引相对于插值后的 A/B 信号断言时的逻辑。

| 值 | 逻辑 |
|---|---|
| 0 | A = 1; B = 1 |
| 1 | A = 1; B = 0 |
| 2 | A = 0; B = 1 |
| 3 | A = 0; B = 0 |

### [15] 幅值监测类型（默认 1）

仅当启用幅值误差检查时有效（v5 central-i 上为 `SinCosSetup[17]=1`；v4 上为 `SinCosSetup[18]=1` — 参见 [17]/[18] 下的版本说明）。确定幅值检查机制。

| 值 | 机制 |
|---|---|
| 0 | Max(\|SIN\|, \|COS\|) |
| 1 | SIN² + COS² |

### [16] 幅值阈值（默认 0）

仅当启用幅值误差检查时有效（v5 central-i 上为 `SinCosSetup[17]=1`；v4 上为 `SinCosSetup[18]=1` — 参见 [17]/[18] 下的版本说明）。确定幅值检查的阈值。若幅值超出阈值，在启用幅值误差检查时会断言幅值误差。该阈值取决于检查机制。

| 值 | SinCosSetup[15]=0 | SinCosSetup[15]=1 |
|---|---|---|
| 0 | 1.4 Vpp | 无效选项 |
| 1 | 2.0 Vpp | |
| 2 | 2.6 Vpp | |
| 3 | 3.1 Vpp | |
| 4 | 无效选项 | 1.0 Vpp to 4.5 Vpp |
| 5 | | 1.5 Vpp to 4.5 Vpp |
| 6 | | 2.0 Vpp to 4.5 Vpp |
| 7 | | 2.5 Vpp to 4.5 Vpp |

### [17] 幅值误差检查（默认 1）

启用/禁用幅值数值检查。当幅值超出设定边界时触发幅值误差。

| 值 | 状态 |
|---|---|
| 0 | 禁用 |
| 1 | 启用 |

> [!note]
> 索引 17 和 18 在固件版本之间互换。在 **v5**（central-i）上，索引 17 为幅值误差检查，索引 18 为频率检查，如本文所述。在 **v4** 上，两者相反：索引 17 为**频率**检查，索引 18 为**幅值**误差检查。每个功能接受的值（0 = 禁用，1 = 启用）及其行为相同；仅数组位置不同。任一位置中 0 或 1 以外的值都将作为超出范围而被拒绝，且 `SinCosSetup[21]` 报告 1。

### [18] 频率检查（默认 0）

仅当插值因子 ≥ 16（`SinCosSetup[6] ≤ 12`）时可用。启用/禁用对 SIN/COS 输入频率的检查。当输入频率连续多个周期超过最大输入频率时触发频率误差。

| 值 | 状态 |
|---|---|
| 0 | 禁用 |
| 1 | 启用 |

### [19] 测试模式（默认 0）

仅当 `SinCosSetup[9]=0` 时可用。确定送往 DSP 的 Z 增量信号上出现的信号。可选范围为 0–7；大于 7 的值将作为超出范围而被拒绝（不写入芯片设置，且 `SinCosSetup[21]` 报告 1）。

| 值 | Z 上的信号 |
|---|---|
| 0 | Z |
| 1 | A xor B |
| 2 | ENCLK |
| 3 | NLOCK |

### [20] 模拟测试模式状态（默认 0）

配置送往 DSP 的增量信号线上出现的信号。用于信号校准。

| 值 | A 上的信号 | B 上的信号 | SDA 上的信号 | SCL 上的信号 |
|---|---|---|---|---|
| 0 | A | B | SDA | SCL |
| 1 | COS+ | COS- | SIN+ | SIN- |

### [21] SIN/COS 状态（默认 0）

表示编码器芯片中 SIN/COS 编码器设置的状态。这是芯片返回的错误消息。对该数组位置的写入/赋值将被拒绝。

| 值 | 状态 |
|---|---|
| 0 | 芯片设置正常。 |
| 1 | 芯片设置未写入：至少有 1 个 `SinCosSetup` 设置超出范围。 |
| 2 | 写入芯片设置失败。 |
| 3 | 芯片设置未写入：`SinCosSetup` 中的某个功能不受芯片支持。 |

## 示例

```text
ASinCosSetup[1]=2        ; signal gain
ASinCosSetup[6]=7        ; interpolation factor 2^(16-7) = 512 counts per cycle
ASinCosSetup[20]=1       ; enter analog test mode (TMA) for calibration
ASinCosSetup[21]        ; query chip settings status
```
