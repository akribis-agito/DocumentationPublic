# 力控制

力误差保护通过监测力误差（指令力减去测量力）来保护力控制运行，并在力误差增长过大时禁用轴——例如当力反馈丢失或负载行为异常时。

- [MaxForceErr](MaxForceErr.md) 设定闭环力控制中使用的限值。超过该限值会在 [ConFlt](../../07-status-and-faults/ConFlt.md) 上引发故障码 1045（力误差超过限值）。
- [MaxForceErrOL](MaxForceErrOL.md) 设定力通路处于开环或信号注入时使用的较大限值。超过该限值会引发故障码 1057（开环力误差过高）。

根据力环是闭环还是开环，会在这两个限值之间自动切换有效限值。如果未定义模拟力反馈，则力环改为引发故障码 1046（力反馈未定义）。
