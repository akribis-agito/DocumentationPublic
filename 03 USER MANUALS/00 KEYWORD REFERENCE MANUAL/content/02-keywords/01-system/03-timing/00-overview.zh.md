# 定时

**概述：**

Agito 控制器以周期计数的形式报告系统定时。该定时可供用户程序功能使用，以便在正确的时刻触发事件。部分定时器关键字也可设置，从而在确定处理时间方面提供更大的灵活性。

本节中所有定时均源自控制器的控制中断，该中断以固定的每秒 16384 个周期运行（每个周期约 61 µs）。这些关键字以三种分辨率呈现该时钟：

- 每控制周期：`CounterUp` 和 `CounterDown` 在每个控制周期推进一次（每秒 16384 次），提供周期精确的加/减计数。
- 每秒：`Time` 源自同一时钟，每 16384 个周期递增一次，即每秒一次。
- 亚微秒级：在 central-i 平台上，`HWTimer` 读取一个快速硬件定时器寄存器，用于以远高于单周期的分辨率测量短时间间隔。

**计时在每个周期中发生的位置：** 每个控制中断首先完成其时间关键工作——读取反馈、运行控制环、并将 PWM 和数字量输出写入硬件——然后才在同一中断的第二个非时间关键部分中更新维护性定时器。`Time` 秒计数器以及 `CounterUp` / `CounterDown` 计数器都在该第二部分中推进，此时本周期的输出已提交到硬件，因此其记账操作绝不会延迟控制输出。位置环、速度环和电流环本身都在每个控制周期以完整的 16384 Hz 执行；不存在更慢的外环，环路之间也不存在抽取。
