# DebugData

保留供 Agito 功能开发和测试使用的数组。

## 概述

`DebugData` 是保留供 Agito 功能开发和测试使用的大型暂存数组（大多数构建上为 200 个元素，某些构建上更大）。其内容和含义**并不固定**，可能在固件构建之间变化，因此不应在生产集成中使用。

## 工作原理

`DebugData` 是单个共享的非轴数组，固件模块直接读写它，以暴露内部值或在开发过程中注入测试条件。各个元素在固件内部通过命名索引寻址，因此任一给定元素的含义完全取决于构建。它所服务的用途示例包括：捕获控制中断时序（在实时中断的起点、中点和终点锁存的计数器）、为测试模拟数字量输入状态、报告 I²t 电机功率限值，以及为波形演示快照运动规划器/位置参考信号。

除下述带版本窗口外，这些赋值随功能开发而增删，因此数组没有稳定布局。从 `DebugData` 读取的任何值，仅应在生成它的确切固件构建的上下文中视为有意义。

## 带版本的 ISR 时序窗口（预发布 AGM800 / AGM800-EC）

这些 Zynq 构建分配 356 个元素（索引 0–355），诊断锁存区仍为 300–331。
专用时序窗口为 332–355；其他构建可能不提供此窗口。解释数据前，必须确认
固件镜像及签名 `0x49535133`。

| 索引 | 含义 |
| --- | --- |
| 332 | 请求/状态：0 关闭，1 开始/清零，2 采集中，3 冻结请求，4 已冻结 |
| 333 | 窗口签名/版本 |
| 334–335 | 全局计时器频率（Hz）、标称中断周期（计数） |
| 336 | 已观测的完整控制周期数 |
| 337–338 | ISR 主体耗时的最新值/最大值 |
| 339–340 | 离线消息/事件阶段耗时的最新值/最大值 |
| 341–342 | 每周期队列辅助函数总耗时的最新值/最大值 |
| 343–344 | 中断入口间隔的最新值/最大值 |
| 345–346 | 超过 1.5 倍标称周期的入口间隔数；主体耗时达到周期的次数 |
| 347–348 | 每周期辅助函数调用数的最新值/最大值 |
| 349–350 | 首次/末次入口时间戳的低 32 位 |
| 351–355 | 最大主体耗时所在周期的阶段耗时、辅助函数总耗时、入口间隔、递增前任务选择值和周期序号 |

版本 1（`0x49535131`）只提供索引 332–350。版本 2 增加同周期峰值关联；独立最大值可能来自不同周期。

只写请求字段。读取快照前等待状态 4；冻结后数据保持不变，直到下次开始/清零。
使用索引 334 将耗时计数换算为时间。采集会引入探针开销；主体耗时不包括 FIQ
封装、编译器入口/出口代码和末次读计时器后的结果发布。入口间隔计数不能代替
硬件丢中断计数器。单个观测窗口通过检查，并不证明最坏情况时序，也不代表其他
硬件配置已经通过资格验证。

## 示例

```text
ADebugData[1]       ; read a development scratch value (meaning is build-specific)
```
